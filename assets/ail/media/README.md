# AIL media fixtures

Audio and video used by A11y Intuition Lab test cases (decision D-023 in `wiki/decisions.md`).

Every file here is generated by a script in this repository, from arithmetic only: no recordings, no samples, no
third-party material. Audio is byte-identical when regenerated. Video is recorded in real time from a canvas in
Chromium, so a regenerated video has the same content but not the same bytes; the checksums below identify the
committed files.
