# Testing kit workspace

This folder is a closed workspace for an AI agent (D-025 to D-028). Settings in `.claude/settings.json` limit the
agent to reading this folder, writing only to `ai-kit/`, and reaching only the local test server.

- Use only the files in this folder. Do not try to read the rest of the repository.
- Write everything you produce to `ai-kit/`.
- Pages to test are served by the project's test mode on `http://127.0.0.1:8090/`; you are given their URLs.
