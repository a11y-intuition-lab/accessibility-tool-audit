AI test procedures for what axe and pa11y miss Not by GDS

These are the test procedures {{ copyInfo.org.name }} (AIL) wrote for the barriers that axe-core and pa11y do not find in the retest. Each procedure is written so that an AI model can follow it, and is adapted from a test in the manual checklist of sa11y, an internal tool that is not public. The procedures here are complete on their own and do not need sa11y. The procedures are in ai-checks.json. How they were run and what they found is described on the method page.

Each procedure has one of three levels:

  • AI: the model can judge from the page as it is: its HTML, accessibility tree, styles and a screenshot.
  • AI with harness: a script must act on the page first, for example press Tab, zoom or hover, and the model judges the result.
  • Person: the model cannot judge it, for example whether captions match the speech. It can at most flag that a person must check.

What the model is given

The script scripts/ai-evidence.mjs collects this evidence for each page. The model is not given the name of the test case, the file name or the URL.
