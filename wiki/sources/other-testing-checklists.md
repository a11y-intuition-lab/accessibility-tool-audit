## A11y Project checklist

- Owner: The Accessibility Project; licence Apache 2.0 (footer "APLv2"); copyright 2013-2024; no last-updated date shown.
- Grouping: 18 sections, mostly **by content type or component**, not by test method: Content, Global code, Keyboard, Images, Headings, Lists, Controls, Tables, Forms, Media, Video, Audio, Appearance, Animation, Color contrast, Mobile and touch.
- Levels: items labelled A "Essential", AA "Ideal Support", AAA "Specialized Support"; covers many but not all A/AA concerns.
- No automation split found; no AI content found.
- Use: shows the common alternative (group by element type). Our method-based grouping is better for scheduling test passes; the element-type view is useful as a second index when picking pages.
